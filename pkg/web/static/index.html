Configuration Guide & Quick Examples

🌐 Multi-Destination Candidate IPs (IPv4 + IPv6)

Configure multiple candidate endpoints under target_ips. Auto-WG will hunt across both v4 and v6:

tunnels:
  - interface: "wgBridge0"
    target_ips:
      - "198.51.100.1"
      - "2001:db8::1"
      - "vps.example.com"

🔀 Policy Routing & Failover (Table 200)

Automatically manage default route failover across multiple upstream links in client mode:

mode: "client"
routing:
  enabled: true
  table: 200
  mode: "priority" # "priority" or "sticky"
  metric: 100

📡 In-Tunnel Health Check (Fast Ping)

Detect DPI packet dropping within 5-10 seconds via ICMP before the WireGuard handshake timer expires:

    tunnel_ping:
      enabled: true
      target_ip: "10.100.0.1"
      interval: 2s
      failure_threshold: 3

🛡️ Passive Peer Mode (MikroTik / Static)

For remote peers that don't run Auto-WG, set hunting: false to monitor without rotating ports:

    hunting: false # Passive monitoring only
    port_range: "20000-30000"
    iptables: true
