Configuration Reference & Field Guide

🌐 Dual-Stack Target IPs (IPv4 + IPv6 + Domains)

Enter multiple destinations in target_ips. Auto-WG rotates through IPv4 and IPv6 to bypass single-IP blocks:

target_ips:
  - "198.51.100.1"
  - "2001:db8::1"
  - "vps.example.com"

🔀 Policy Routing Failover (Table 200)

Auto-WG dynamically manages ip route replace default dev wgBridgeX table 200 when links stall:

routing:
  enabled: true
  table: 200
  mode: "priority"
  metric: 100

📡 Fast In-Tunnel ICMP Ping

Sends periodic lightweight pings through the tunnel. Confirms dead links in 5-10s before handshakes time out:

tunnel_ping:
  enabled: true
  target_ip: "10.100.0.1"
  interval: 2s
  failure_threshold: 3

🛡️ Passive Monitoring Mode (MikroTik / Static)

Disable hunting for peers running stock WireGuard without Auto-WG. Still monitors & pings without port rotation:

hunting: false
port_range: "20000-30000"
iptables: true
