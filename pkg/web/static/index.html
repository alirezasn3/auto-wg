Field reference

Dual-stack targets

List several destinations; Auto-WG rotates between them when one is blocked.

target_ips:
  - "198.51.100.1"
  - "2001:db8::1"
  - "vps.example.com"

Policy routing failover

Keeps ip route replace default dev wgX table 200 pointed at the healthy tunnel.

routing:
  enabled: true
  table: 200
  mode: "priority"

In-tunnel ping

Detects a dead link in seconds, well before the handshake times out.

tunnel_ping:
  enabled: true
  target_ip: "10.100.0.1"
  failure_threshold: 3

Passive mode

For peers running stock WireGuard: monitor and ping without rotating ports.

hunting: false
port_range: "20000-30000"
